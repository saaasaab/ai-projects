Front / Back Pass Sort Visualizer

Each pass loops through the list. The first number goes onto the stack. Every next number compares to the previous number from the current pass list. Greater goes to the back, smaller goes to the front, equal gets inserted directly next to the matching value already in the stack. Repeat passes until sorted.

Rule:
1. Start each pass with an empty stack.
2. First item goes on the stack.
3. For every next item:
   - if current > previous item in the pass list: push to back
   - if current < previous item in the pass list: unshift to front
   - if current === previous: insert next to the matching value already in the stack
4. When pass is done, the stack becomes the next list.
5. Repeat until the list is sorted.
